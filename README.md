# بوت التدقيق النصي الذكي
### Smart Arabic Text Bot — Blumark24 MVP Demo

أداة ذكاء اصطناعي لتدقيق النصوص العربية وتحسين صياغتها، مبنية على React + Vite.

---

## المميزات

- ✅ واجهة عربية RTL بالكامل
- ✅ تدقيق إملائي للنصوص العربية
- ✅ تحسين الصياغة والأسلوب
- ✅ ترتيب الكلام والفقرات
- ✅ نتيجة نهائية شاملة
- ✅ نسخ النص بنقرة واحدة
- ✅ تحميل النتيجة كملف TXT
- ✅ رفع ملفات TXT وقراءتها
- ✅ إحصائيات النص (كلمات، حروف، جمل)
- ✅ تصميم داكن Premium

---

## التقنيات المستخدمة

- **React 18** — واجهة المستخدم
- **Vite 5** — بناء وتطوير سريع
- **CSS Custom Properties** — تصميم متجاوب
- **خط Cairo / Tajawal** — خطوط عربية احترافية

---

## تشغيل المشروع محلياً

```bash
npm install
npm run dev
```
